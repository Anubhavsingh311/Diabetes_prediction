# Diabetes Prediction System

A machine learning-based web application that predicts the likelihood of diabetes using patient health parameters.

## Live Demo

**[Open Diabetes Prediction System](https://anubhavsingh311.github.io/Diabetes_prediction/)**

## Repository

[GitHub – Diabetes_prediction](https://github.com/Anubhavsingh311/Diabetes_prediction)

## Features

- Diabetes risk prediction using health-related inputs
- Interactive and responsive web interface
- Backend API integration for predictions
- Prediction probability and result display
- Model development and analysis in Jupyter Notebook

## Project Structure

```text
Diabetes_prediction/
├── backend/      # Prediction API and model
├── frontend/     # Web application
├── notebook/     # Model development
├── .github/      # GitHub Actions workflows
├── LICENSE
└── README.md
```

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, FastAPI
- **Machine Learning:** Scikit-learn
- **Deployment:** GitHub Pages and Render

## Disclaimer

This project is intended for educational purposes only. Predictions are not a substitute for professional medical advice or diagnosis.
