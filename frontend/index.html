Privacy

Your inputs are sent directly to the prediction API over HTTPS. Nothing is saved to a database, and no analytics or third-party trackers are used.

First request may be slow

The model is hosted on a free server that sleeps when idle. The first prediction can take up to a minute while it wakes up.

How it works

About the model

A transparent overview of the machine learning system behind each prediction.

Algorithm Gradient Boosting Classifier
Classification threshold 0.21
Input features 8
Explainability SHAP values

The threshold is set to 0.21 instead of the default 0.50, so the model flags a case as positive when the estimated probability is 21% or higher. This favours catching more potential cases (higher recall) for screening. The classification is always made by the backend.

Prediction workflow

  1. Input

    You enter eight health indicators in the form.

  2. Validate

    Values are checked in the browser and again by the API.

  3. Predict

    The Gradient Boosting model estimates a probability.

  4. Classify

    The backend compares it with the 0.21 threshold.

  5. Report

    The probability and classification are shown to you.

GlycoSense

Diabetes Prediction System — an educational project that applies a Gradient Boosting Classifier to eight health indicators to estimate the likelihood of diabetes, with SHAP-based explainability.
